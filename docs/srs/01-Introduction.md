# Introduction

## Purpose

This document provides an overview of the KISS Vocational Training Management Portal project, its objectives, and the scope of this Software Requirements Specification (SRS).

## Project Name

**KISS Vocational Training Management Portal**

## Document Purpose

This SRS document defines the complete functional and non-functional requirements for the KISS Vocational Training Management Portal—a web-based ERP and Learning Management System designed to streamline vocational training operations at KIIT University.

## Intended Audience

- Project Managers
- Software Architects
- Development Team Members
- QA and Testing Teams
- System Administrators
- Stakeholders and Decision Makers

## Document Scope

This SRS covers:
- Functional requirements for all three user roles (Student, Teacher, Admin)
- Non-functional requirements (performance, security, scalability)
- System use cases
- Assumptions and constraints
- Interface requirements

This SRS does **NOT** cover:
- UI/UX mockups or design specifications (see docs/UI-UX/README.md)
- Implementation code or technical architecture (see docs/SDD/)
- Database schema in detail (see docs/SDD/02-Database-Design.md)

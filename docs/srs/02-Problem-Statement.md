# Problem Statement

## Overview

KIIT University's vocational training program currently lacks a centralized, integrated system to manage the complexity of enrollment, course allocation, attendance tracking, grading, and certificate distribution.

## Current Challenges

### 1. Manual Enrollment Process
- Enrollment is managed through paper forms or disconnected spreadsheets
- No real-time tracking of enrollment status
- High error rates in data entry
- Difficulty in enforcing staggered enrollment windows

### 2. Absence of Automated Batch Allocation
- Course batches are assigned manually, leading to inefficient resource utilization
- No fairness or transparency in allocation mechanisms
- Time-consuming process prone to human error
- Inability to handle batch switching requests efficiently

### 3. Disparate Attendance and Grading Systems
- Attendance is tracked manually or in separate systems
- Teachers maintain grades in isolated spreadsheets
- No integrated gradebook with draft/publish workflows
- No real-time visibility into student progress
- Difficulty in maintaining grade integrity

### 4. Manual Certificate Generation
- Certificates are generated manually after course completion
- Time-consuming and error-prone process
- No automated tracking of certificate issuance
- Students cannot retrieve certificates independently

### 5. Lack of Centralized Communication
- No structured grievance management system
- Feedback collection is ad-hoc and not standardized
- Limited visibility into student concerns and satisfaction

### 6. Absence of Administrative Oversight
- Admins cannot view real-time metrics on enrollment, allocation, grievances, or feedback
- No unified dashboard for system monitoring
- Difficulty in generating reports for analysis

### 7. No Role-Based Access Control
- System security is not enforced
- No audit trail for data changes
- Unauthorized access to sensitive information is possible

## Desired Outcome

A unified, web-based ERP + LMS platform that:
- Automates enrollment, allocation, and grading workflows
- Provides role-based access control (Student, Teacher, Admin)
- Offers real-time dashboards and progress tracking
- Generates certificates automatically
- Manages grievances and feedback systematically
- Ensures data integrity and security
- Scales to support the entire vocational training program

## Business Value

| Dimension | Benefit |
|-----------|---------|
| **Efficiency** | Reduce manual work; automate repetitive tasks |
| **Accuracy** | Minimize data entry errors; ensure data consistency |
| **Transparency** | Provide students real-time progress visibility |
| **Fairness** | Use algorithmic allocation; enforce consistent policies |
| **Compliance** | Maintain audit trails; enforce role-based access |
| **Scalability** | Support growing enrollment without degradation |

## Success Criteria

The system will be considered successful if it:
1. Reduces enrollment processing time by at least 50%
2. Automates 100% of batch allocation workflow
3. Enables teachers to complete grading 3x faster
4. Generates certificates within 1 business day of course completion
5. Achieves 99.5% system uptime
6. Supports concurrent usage by 200+ users without degradation
